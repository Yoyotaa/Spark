Première version publique de **Spark**, le copilote visuel : A.R.I.A voit ton écran et te répond, par écrit ou à la voix.

### Ce qu'elle sait faire
- **Voir** : chaque question part avec une capture de l'écran (Spark n'apparaît jamais dessus).
- **Écouter** : push-to-talk (F8) ou écoute continue avec le mot d'activation « Aria ». Reconnaissance vocale d'Apple sur macOS, en direct.
- **Répondre** : en quelques secondes, au fil de l'eau, lue à voix haute (voix système ou neuronale Gemini).
- **Coup d'œil** (⌥⇧D) : une analyse de l'écran sans parler ni écrire.
- **Mode proactif** (option) : A.R.I.A intervient d'elle-même quand elle voit quelque chose d'important.
- **Au choix** : Gemini (gratuit), Claude, OpenAI ou compatibles (OpenRouter, Ollama…). Clés dans le trousseau du système.
- **Discrète** : surcouche transparente qui laisse passer les clics, icône dans la barre des menus, tout est réglable.

### Installation
- **macOS 14+** : décompresse `Spark-v0.1.0-macOS.zip`, glisse l'app dans Applications, puis **clic droit › Ouvrir** au premier lancement (app non signée par Apple).
- **Windows 10/11** : `Spark-v0.1.0-Windows-setup.exe`. SmartScreen : « Informations complémentaires › Exécuter quand même ».

### Limites connues
- La version Windows n'a pas encore été testée sur une vraie machine.
- Les jeux en plein écran exclusif (Windows) masquent les surcouches : utilise le mode « fenêtré sans bordure ».
- Sur le niveau gratuit de Gemini, Google peut utiliser les requêtes pour améliorer ses produits.
